🚀 Block_ID 2.1.0-Release Release 最新 重大更新
ForgeFabric
重大版本更新：新增收藏夹/组系统、历史记录功能，删除常用方块自动统计，UI 交互全面升级，替换模式源方块复制优化。
⭐
收藏夹/组系统
  • 多组管理：支持创建、重命名、删除多个收藏组，每组独立管理方块列表
  • 默认收藏组：内置"默认收藏"组，开箱即用
  • 快捷添加：方块列表右侧点击星标即可添加/移除收藏
  • 实时更新：添加/移除收藏后列表立即刷新，无需重新打开界面
  • 数据持久化：收藏数据保存在配置文件中，重启不丢失
📋
历史记录
  • 自动记录：每次复制 ID 或指令自动记录到历史
  • 最近20条：保留最近20条复制记录，方便回溯
  • 方块名称显示：历史记录显示方块中文名而非原始 ID，更直观
  • 一键重复制：点击历史记录即可重新复制到剪贴板
  • 模式标识：每条记录标注 ID / Set / Replace 模式
🔧
替换模式优化
  • 源方块无放置比例：替换模式下源方块不显示放置比例滑块，符合 WorldEdit 语义
  • 复制不带比例：源方块复制结果仅包含 ID 和属性，不带百分比前缀
  • 目标方块保留比例：目标方块仍支持放置比例设置，格式为 50%minecraft:stone
🔄
UI 优化
  • 标签切换：中列增加"收藏夹 / 历史记录"标签切换
  • 删除常用方块：移除原有的常用方块自动统计功能
  • 滚轮浏览：全部方块列表使用滚轮滚动，操作流畅
  • 布局稳定：收藏夹区域组名、按钮、分割线、列表布局经过多轮优化
🐞
Bug 修复
  • 修复收藏夹列表不刷新：添加/移除收藏后列表立即更新
  • 修复源方块复制带比例：替换模式源方块复制结果不再包含百分比
  • 修复历史记录显示 ID：改为显示方块中文名
  • 修复列表消失问题：修复非替换模式下中列列表异常消失的 Bug

🚀 Block_ID 2.0.2-Beta Beta
ForgeFabric
在 2.0.0 重构基础上，新增方块属性设置与放置率权重功能，界面全面美化，交互体验大幅提升。
⚙️
核心功能扩展
  • 方块属性设置：已选列表每项新增 ⚙ 按钮，展开属性编辑面板，支持所有 BlockState 属性可视化切换，输出 WorldEdit 格式 minecraft:stone_slab[type=top,waterlogged=false]
  • 属性中文映射：内置 50+ 属性名与 60+ 属性值中文翻译，如 facing→朝向、half→半层、north→北
  • 放置率权重滑块：已选列表每项内置迷你滑块，拖动调整放置概率，输出 50%stone,50%grass
  • Ctrl+左键精确输入：按住 Ctrl 点击滑块或百分比文字，弹出数字输入框精确设置 1-100
  • 自动归一化：新增平均分配、调整后按比例补满、删除时重新分配，总和始终保持 100%
🎨
UI 与交互优化
  • 属性面板小卡片化：改为左下角 230px 小卡片，紧凑不遮挡列表
  • 滑块可拖动：放置率滑块支持按住拖动实时调整
  • 三列半透明面板：添加半透明背景与顶部蓝色高亮边线
  • 搜索栏占位文字：添加"搜索..."提示
  • 选中项高亮条：已选方块左侧添加绿色高亮指示条
🐞
修复与优化
  • 修复空气方块重复显示，双重过滤仅保留 minecraft:air
  • 修复搜索后滚动条范围计算错误
  • 修复替换模式下右列滚动失效
  • 修复搜索后 ➕/✔ 图标消失
  • Fabric 版新增常用方块自动收集事件监听
  • 修复 FrequentBlockManager 副作用问题

🚀 Block_ID 2.0.0-Beta Beta 重大更新
ForgeFabric
从 1.2.0-Alpha 到 2.0.0-Beta，本次更新是一次全面重构。无论是 UI 视觉、交互逻辑还是底层数据管理，都有跨越式的提升。
🎨
UI 与交互优化
  • 全新三列布局：左侧"全部方块"，中间"常用方块"，右侧"已选列表/确认区"，空间利用率大幅提升
  • 双模式切换：顶部按钮支持"复制模式/替换模式"与"ID复制/指令模式"任意组合切换
  • 动态图标操作： · 左侧/中间列表每行末尾新增 ➕ 图标，点击可手动添加至常用方块 · 已添加的常用方块图标自动变为 ✔（绿色） · 中间"常用方块"列表每行末尾新增 ➖ 图标，点击可手动移除
  • 智能搜索栏：支持中文名、英文 ID、拼音首字母搜索
  • 自适应布局：全屏/小窗口下所有元素自动计算位置，彻底解决按钮遮挡或列表显示不全
⚙️
核心功能扩展
  • ID复制模式：复制纯 ID（无指令前缀），支持多选，多个 ID 以逗号分隔；替换模式复制格式为"源ID 目标ID"（含空格）
  • 指令复制模式：一键复制 //set 或 //replace 完整 WorldEdit 指令到剪贴板
  • 替换模式优化：源方块与目标方块分列显示，复制格式严格保持"源ID 目标ID"（含空格）
  • 常用方块统计规则： · 原版/模组方块放置 15 次自动加入（手动添加也有效） · WorldEdit 指令使用 3 次自动加入 · 支持手动添加/移除，完全自定义
🔧
底层与稳定性
  • 配置系统重构：从 ForgeConfigSpec 迁移至 Gson JSON 存储，彻底解决配置文件读写崩溃
  • 统计逻辑修复：双保险策略（右键点击 + 聊天指令监听），确保常用方块统计准确
  • 按键响应优化：修复搜索框焦点死循环、按钮点击无效等遗留 Bug
  • 多语言支持：内置简中、繁中、英、日、法、德、西、葡、俄 9 种语言
  • 新增前置依赖：Cloth Config API（任何版本）
🐞
主要修复（相对 Alpha 1.2.0）
  • 修复"替换模式复制格式缺少空格"的 Bug
  • 修复"WorldEdit 指令无法被统计"的问题
  • 修复"搜索栏无法输入"、"按钮无反应"等交互故障
  • 修复"常用方块列表不刷新"的数据同步问题
