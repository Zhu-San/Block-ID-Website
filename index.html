ABOUT

为建筑玩家而生

无需再痛苦翻查资料或手动输入复杂的英文 ID

Block ID 专为建筑、地图、红石、生存玩家打造。本模组提供极致直观的图形化管理界面，支持一键生成并复制 WorldEdit 指令。

采用三列动态布局（全部 / 常用 / 已选），依托强大的多音字智能拼音引擎，让你用中文习惯丝滑操作，显著提升创造与生存效率。

从按下 G 键打开界面，到搜索、选择、复制指令——整个过程不超过 3 秒。

FEATURES

六大核心功能

每一个细节都为提升你的建造效率而设计

智能拼音搜索

实现全拼（shitou）、声母缩写（st）、多音字混合（输入 shanzhang 或 shanchang 均可精准搜出"闪长岩"）的无缝匹配。支持中文原名、英文 ID、拼音全拼、拼音首字母混合模糊匹配。

常用方块收藏

在"全部方块"点击 + 加入常用，点击 − 移除。收藏列表自动保存至本地配置文件 .minecraft/config/block_id.json，即便游戏重开或服务器更换，专属常用列表永远不会丢失。

动态 UI 布局

全 UI 采用动态坐标计算，无论窗口大小如何拉伸，搜索框、按钮、列表均无重叠。支持可拖拽的可视化滑动条，自动过滤不可放置的非方块物品，原生搜索框拥有半透明多语言占位符。

一键复制 ID C / G

按下 C 键即刻复制手持物品的完整方块 ID（如 minecraft:stone）；按下 G 键秒开主界面。无需切换窗口、无需任何手动操作，点开即用。

WorldEdit 深度集成

完美集成 //set 与 //replace 指令。支持方块属性设置（如 minecraft:stone_slab[type=top]）与放置率权重（如 50%stone,50%grass），滑块拖动或 Ctrl+左键精确输入，总和自动归一化。多选后一键生成完整指令并复制到剪贴板。

高性能流畅体验

底层采用视口裁剪（Viewport Culling）技术，只渲染当前屏幕可见区域，并预计算所有方块的拼音缓存。即使在上千种方块的列表中，滚动依然保持 60 FPS 丝滑流畅，彻底告别滚动卡顿。

FAQ

常见问题

遇到问题？先在这里找找答案

Q:按下 G/C 键无反应？
A:请检查是否与其他模组按键冲突。进入游戏设置 → 控制 → 按键绑定，找到"方块ID"分类重新绑定按键即可。
Q:替换模式的目标栏无法搜索？
A:点击目标搜索框获取焦点（光标闪烁），即可进行独立的拼音/中文/英文搜索。当前仅替换模式开启该功能。
Q:为什么列表越往下滑越卡？
A:请务必更新至 v2.0.3.2-Release 或更高版本。此版本已彻底重构底层渲染，内置视口裁剪优化，滚动十分流畅。
Q:替换模式下如何取消已选方块？
A:左侧点击加入"源"，中间点击加入"目标"，右侧列表展示已选源/目标。直接点击右侧列表中的方块，即可将其移除。
Q:为什么列表中看不到空气等方块？
A:为保持界面整洁，防止误选技术方块导致 WorldEdit 报错，模组自动过滤了空洞气、虚空气及无物品形态的方块，保留了可操作的"空气"供你使用。
Q:如何彻底重置常用列表？
A:直接删除配置文件 .minecraft/config/block_id.json，重启游戏即可恢复默认状态。
